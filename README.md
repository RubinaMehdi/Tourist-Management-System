# Tourist Management System

A comprehensive system to manage tourist bookings, tour guides, and administrative tasks.

## Features
- **Admin Panel:** Manage packages, hotels, and transport.
- **Tourist Panel:** Book tours and make payments.
- **Tour Guide Panel:** View assigned tours and manage availability.

## Tech Stack
- **Language:** Java (or Python)
- **GUI:** Swing / Tkinter
- **Data Persistence:** File Handling (.txt or .csv files)
- **OOP Concepts:** Interfaces and Abstraction
